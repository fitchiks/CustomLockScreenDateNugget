# Custom Lock Screen Date (Nugget)

[English](README.md) · **Русский**

Возвращает длинный формат даты на экране блокировки iOS 26 — «Пятница, 18 сентября»
вместо укороченного «Пт 18 сен», который Apple оставила без возможности настройки.

Работает на движке восстановления [LeminLimez/Nugget](https://github.com/leminlimez/Nugget).
Поддерживаются iOS **26.0 – 26.6.2**.

## Как это работает

iOS рисует дату на локскрине по фиксированному короткому шаблону (`EEE d MMM`). Сам шаблон
изменить нельзя, но штатный ключ CoreFoundation `AppleICUDateTimeSymbols` позволяет
переопределить *короткие* названия месяцев и дней недели. Утилита подменяет эти короткие
названия длинными — и система рисует полную дату, думая, что печатает сокращения.

Пишется один файл — пользовательские настройки
`HomeDomain/Library/Preferences/.GlobalPreferences.plist`. Управляемый файл не трогается,
поэтому утилита не конфликтует с другими твиками Nugget (Liquid Glass и т.д.).

## Возможности

- Все системные языки iPhone и все регионы — выбираешь ту же пару, что стоит на устройстве.
- Названия месяцев и дней редактируются: любую из 19 строк можно заменить на свою.
- Пресеты по языкам из CLDR, с проверенными вариантами для ru / uk / be / kk.
- Опциональная запятая после дня недели («Пятница, 18 сентября»).
- Опциональный перевод времени в 12/24-часовой формат.
- Живой предпросмотр и индикатор совпадения с локалью подключённого устройства.
- Двуязычный интерфейс (русский / английский).

## Требования

- Windows с приложением «Apple Devices» (или iTunes).
- Python 3.12 (для 3.14 нет готовых сборок `lzfse`/`pylzss`).
- **«Найти iPhone» должен быть выключен** перед применением.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Запуск

```powershell
python lockscreen_date.py
```

На Windows программа сама перезапустится с правами администратора (нужны, чтобы сохранить
сопряжение с устройством). Подключи iPhone, разблокируй его, выбери язык и регион, при
желании поправь названия и нажми **Применить**. Устройство перезагрузится для применения.

Кнопка **Убрать твик с устройства** возвращает стандартный формат даты iOS.

## Предупреждение

**Не обновляйся на iOS 27.** Apple закрыла механизм частичного восстановления, на котором
держится Nugget — применение твиков там стирает устройство.
